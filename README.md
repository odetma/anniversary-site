# 8 Years of Us - Anniversary Website

A beautiful and interactive website celebrating 8 years of love, laughter, and pizza moments! 🍕❤️

## Features

- 🎉 Interactive timeline of your 8-year journey
- 🏆 Hall of Fame with fun awards and achievements
- ❓ Fun quiz to test how well you know each other
- 📱 Responsive design that works on all devices
- 🎨 Beautiful animations and transitions
- 🍕 Pizza-themed design elements

## Getting Started

### Prerequisites

- Node.js (v14 or later)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   # or
   yarn install
   ```

### Running the Development Server

```bash
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website in your browser.

### Building for Production

```bash
npm run build
# or
yarn build
```

### Starting the Production Server

```bash
npm run start
# or
yarn start
```

## Customization

You can customize the content by editing the following files:

- `pages/index.tsx` - Home page content
- `pages/timeline.tsx` - Timeline data and layout
- `pages/hall-of-fame.tsx` - Awards and achievements
- `pages/quiz.tsx` - Quiz questions and answers

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion (for animations)
